# Life Coach Reiki 🌿

Projeto de desenvolvimento de uma página web para o **Life Coach Reiki**, criada com HTML e CSS, com foco em uma apresentação simples, elegante e responsiva.

## 📌 Sobre o projeto

O site apresenta informações sobre serviços de Life Coaching e Reiki, destacando um webinar gratuito e os principais benefícios do acompanhamento de um profissional.

A página foi desenvolvida seguindo uma proposta visual com:

- Fundo em tom creme;
- Títulos com fonte **Fraunces**;
- Textos com fonte **Inter**;
- Botões arredondados;
- Seção de destaque para o webinar;
- Seção de benefícios;
- Rodapé com links e redes sociais;
- Layout responsivo para diferentes tamanhos de tela.

🔗 **[Acessar o projeto no GitHub Pages](https://biancayy898.github.io/Landing-Page/)**

## 🖥️ Estrutura do site

O projeto é dividido nas seguintes partes:

### Header

O cabeçalho contém:

- Logo do projeto;
- Links de navegação:
  - Read
  - Listen
  - Talk
  - Transform

- Botão **Know Reiki**;
- Botão **Consult with Reiki**.

### Hero

A seção principal apresenta:

- Identificação de **Free Webinar!**;
- Título principal;
- Descrição do webinar;
- Botões **Learn More** e **Register**;
- Imagem principal do projeto.

### Webinar

A segunda seção apresenta um convite para participar do webinar gratuito, com uma breve explicação sobre o acompanhamento de um Life Coach.

Possui o botão **Join Us**.

### Benefícios

A seção de benefícios apresenta duas informações principais:

1. **Gain clarity, focus, and confidence in your abilities**

   Explica como o acompanhamento pode ajudar na identificação de dificuldades, criação de objetivos e desenvolvimento pessoal.

2. **Create the life you want**

   Apresenta a proposta de ajudar o usuário a desenvolver mais clareza e direção para alcançar seus objetivos.

### Footer

O rodapé possui:

- Logo;
- Links informativos;
- Linha divisória;
- Direitos autorais;
- Ícones de redes sociais.

## 🎨 Tecnologias utilizadas

### HTML5

Utilizado para criar a estrutura e organizar o conteúdo da página.

### CSS3

Utilizado para:

- Estilização da página;
- Organização dos elementos;
- Cores;
- Tipografia;
- Espaçamentos;
- Botões;
- Responsividade.

### Google Fonts

Foram utilizadas as fontes:

- **Fraunces** — títulos;
- **Inter** — textos e elementos de navegação.

## 📱 Responsividade

O projeto possui regras de CSS para adaptar a página a diferentes tamanhos de tela.

Foram utilizados `media queries` para ajustar:

- Cabeçalho;
- Menu de navegação;
- Tamanho dos títulos;
- Botões;
- Imagem principal;
- Seção de benefícios;
- Rodapé.

Em telas menores, os conteúdos são reorganizados para facilitar a visualização e a navegação.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma página web moderna e responsiva para apresentar os serviços de **Life Coaching e Reiki**, utilizando uma estrutura organizada e uma identidade visual elegante.

## 👩‍💻 Desenvolvimento

Projeto desenvolvido como atividade de desenvolvimento web, utilizando conhecimentos de **HTML5 e CSS3**.
